## uWolf runtime

The browser runtime in `runtime/` is based on
[uWolf](https://github.com/dibdot/uWolf), written by Dirk Brenken with Claude
Opus 4.8 credited by the upstream project. The audited source baseline is
commit `80571bbde9897881ca2d9ecaf30e81cb308f37bb`.

uWolf and this modified distribution are provided under the GNU General Public
License version 3. See `LICENSE` and `runtime/LICENSE`.

Scene Access Gateway modifications include same-origin data loading,
Wolfenstein/Spear profiles, portal and CRT messaging, mobile and wide-screen
controls, scene zoom integration, and presentation changes. The specific
modified runtime files are recorded in `SOURCES.md`. The integration controller
and repository tooling are maintained as part of this GPL-3.0 distribution.
